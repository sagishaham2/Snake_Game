# 🐍 Snake Game (Python & Turtle)

A classic arcade Snake game built in Python using Object-Oriented Programming (OOP) principles and the built-in `turtle` graphics library.

## ✨ Features
- **Classic Gameplay:** Smooth grid-based movement and collision detection (walls and tail).
- **Persistent High Score:** Automatically saves and loads the all-time high score using a local `data.txt` file.
- **Modular Architecture:** Clean separation between game loop (`main.py`), snake logic (`snake.py`), food generation (`food.py`), and UI (`scoreboard.py`).

## 🎮 Controls
- **Up Arrow (`↑`):** Move Up
- **Down Arrow (`↓`):** Move Down
- **Left Arrow (`←`):** Move Left
- **Right Arrow (`→`):** Move Right
